# CLI wiring and parameter changes

The command-line side of the review fixes, plus the parameter changes that were agreed
on. Each behaviour change has a test; the tools were smoke-run on SWISSIMAGE, the
Copernicus DEM, ESA WorldCover and hand-built archives.

## Shared code

- `internal/cli` holds what geotiff2pmtiles and pmtransform duplicated: `ParseColor`,
  `ParseOptionalColor`, `FillColors`, `HumanSize`, `IsFlagSet`, the profiling flags and
  `MakeTmpDir`.
- `--cpu-profile` / `--mem-profile` in both tools; `-cpuprofile` / `-memprofile` still work
  and are marked deprecated.
- The signal cleanup also removes `<output>.partial`, which Finalize writes next to the
  output. Temp dirs left by killed runs (`.geotiff2pmtiles-tmp-*`, `.pmtransform-tmp-*`)
  are reported at startup, not deleted.

## Fill colours

- `--fill-color` is split into `--nodata-color` (recolours transparent/nodata pixels) and
  `--fill-missing` (solid tiles at positions inside the bounds without data; `none` or ""
  turns it off). `--fill-color` remains a deprecated alias for both and cannot be combined
  with them. The library fields are `Config/TransformConfig.NodataColor` and
  `.FillMissing`.
- geotiff2pmtiles: `--nodata-color none`, `--fill-missing 0,0,0,0` (skipped for jpeg unless
  set). Output tiles are unchanged from the old default.
- pmtransform: both default to none. `--nodata-color` re-encodes; `--fill-missing` alone
  copies the tiles byte for byte and adds pre-encoded fill tiles.

## pmtransform

- `tile.SelectTransformMode` picks the mode for pmtransform and the integration helpers
  (which still rebuilt whenever the min zoom was below the source's). `tile.Transform`
  now adds levels below the source's min zoom itself in passthrough and re-encode mode.
- Source metadata keys the writer does not derive (a scene list, say) pass through via
  `WriterOptions.Extra`; a non-terrarium `encoding` is carried forward.
- Output bounds use `Header.Bounds()` (exact E7) instead of the float32 fields.

## geotiff2pmtiles

- Inputs in different CRSs are accepted. Every source's CRS is checked right after
  opening (unknown, missing, user-defined 32767); the wroge/crs note is printed per CRS;
  the auto max zoom follows the finest source; holes are searched per CRS; the
  description lists all EPSG codes and gives a CRS extent only for a single CRS.
- `--source-epsg N` sets the CRS of every input.
- Terrarium takes `--nodata` as any float (overrides GDAL_NODATA of every source);
  `--nodata-tolerance` and `--nodata-flood` stay RGB-only.
- The auto rescale range skips sources without usable values (all nodata) when others
  have them.
- Help for `--rescale`, `--rescale-range`, `--nodata`, `--mem-limit`; the banner prints the
  resolved auto spill limit ("Spill queue").

## Utilities

- checkpmtiles: flag package (`-h`, `-version`, exit 2 on usage errors); reads directories
  with the archive's internal compression and follows leaves to any depth; fails archives
  with MinZoom > MaxZoom, no addressed tiles, or a header tile count that disagrees with
  the directories.
- pmheader: `--sync-metadata` (default true) updates the metadata keys minzoom, maxzoom,
  format, bounds and center that the metadata has; metadata and directories are read in
  the archive's compression, leaves to any depth; `--rebuild-dirs` switches to gzip;
  `-version`; exit 2 on usage errors.
- coginfo: flag package, `-version`, `-raw` (the raw IFD 0 tags, nodata, first tile bytes
  and float range that `cmd/debug` printed). `cmd/debug` is gone.
