# pmmerge: merge PMTiles archives of differing max zooms

New tool `pmmerge [flags] -o <output.pmtiles> <input.pmtiles>...`.

- Output zoom range: the highest input min zoom to the highest input max zoom.
- Above its own max zoom an input's max-zoom tiles are cropped and scaled up (nearest
  neighbour) into the positions they cover, so e.g. z12 regions still have z13/z14 tiles.
- Overlaps: the higher-max-zoom input wins, ties go to argument order; tiles are
  composited per pixel (straight-alpha "over"; terrarium: no blending).
- Every input that gets scaled up is named in a warning; `--max-zoom` above every input's
  max zoom is refused.
- A sole native tile in the output format, or an opaque top tile, is copied byte for byte.
- `tile.Merge` / `tile.MergeInput` / `tile.MergeConfig` in `internal/tile/merge.go`;
  pmtransform's tile size discovery moved to `tile.SourceTileSize` for both tools.
- `make build-merge`, part of `build-all`; built for releases in CI.
- Tests: `TestMergeMixedResolutions`, `TestCompositeUnderBlendsPartialAlpha`,
  `TestUpsampleCropTwoLevels`. Smoke-run on
  the Natural Earth example merged with a z3 copy of itself; checkpmtiles passes.
